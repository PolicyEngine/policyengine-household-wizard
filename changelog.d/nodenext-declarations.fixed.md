The type declarations now name the file of every relative import (`./draft.js`, `./adapters/index.js`), so an app that resolves modules with `moduleResolution: "NodeNext"` and checks libraries (`skipLibCheck: false`) can import every export path. Such an app used to get TS2834 errors and lose re-exported names, such as `createBlankDraft` from the root. The build now type-checks three apps against `dist` (`bun run check:consumer-types`), in CI too: NodeNext ESM, NodeNext CommonJS (TypeScript 5.8 or later, which lets CommonJS `require` an ESM package) and Bundler.
