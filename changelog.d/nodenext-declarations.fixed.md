The type declarations now name the file of every relative import (`./draft.js`, `./adapters/index.js`), so an app that resolves modules with `moduleResolution: "NodeNext"` and checks libraries (`skipLibCheck: false`) can import every export path. Such an app used to get TS2834 errors and lose re-exported names, such as `createBlankDraft` from the root. The build now type-checks a NodeNext app and a Bundler app against `dist` (`bun run check:consumer-types`), in CI too.
